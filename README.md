## ⚡ Características del Ecosistema

Directorio web de arquitectura estática moderna (SSG) desarrollado en **Astro 4**, **Tailwind CSS** y **TypeScript**, diseñado para monetización híbrida de alto margen sin costos fijos:

1. **Rendimiento Máximo:** Compilación 100% estática HTML/CSS con 100/100 Core Web Vitals en Google.
2. **Arquitectura de SEO Programático (pSEO):**
   - Integraciones transaccionales (`/integraciones/[slug]`) con esquema JSON-LD `HowTo`.
   - Comparativas de SaaS vs Open-Source (`/alternativas/[slug]`) con esquema `Article`.
   - Directorio filtrable en tiempo real (`/directorio`) sin recargas de página.
3. **Monetización Híbrida Integrada:**
   - **Plantillas n8n:** Catálogo con checkout modal de **Payhip** (5% de comisión, 0 USD/mes fijo) y botones a **Gumroad Discover**.
   - **Pack Completo (Bundle):** Landing de alta conversión en [`/bundle`](https://irvinggaona124-code.github.io/autohub-directory/bundle/) vendiendo los 4 activos por **49 USD** (ahorro superior al 70%).
   - **Pases Fast-Track B2B:** Página de envío en [`/enviar`](https://irvinggaona124-code.github.io/autohub-directory/enviar/) para fundadores que pagan 25 USD por revisión en 48h con enlace dofollow permanente o 99 USD/mes por patrocinio.
   - **Onboarding Post-Compra:** Página de descarga digital inmediata en `/gracias`.
4. **Flujos n8n Reales Descargables:** Archivos `.json` válidos incluidos en `public/workflows/`.
5. **Marketing Kit Incluido:** Copys para Show HN (Hacker News), posts para Reddit, 8 pines de Pinterest SEO y secuencia de bienvenida para beehiiv en `marketing-kit/`.

## 🚀 Comandos Rápidos

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo local
npm run dev

# Compilar sitio estático para producción
npm run build

# Compilar y desplegar actualización en vivo a GitHub Pages
npm run deploy
```
